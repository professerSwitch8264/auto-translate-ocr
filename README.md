1. โปรเจคนี้ทำอะไรได้บ้าง? (ฟีเจอร์หลัก)
โปรแกรมนี้ทำหน้าที่เป็น "แว่นตาแปลภาษา" ที่ลอยอยู่เหนือทุกโปรแกรม (Overlay) โดยมีฟีเจอร์เด่นๆ ดังนี้:

ครอบแล้วแปล (Screen Cropping): ลากกรอบสี่เหลี่ยมเพื่อระบุจุดที่มีข้อความ (เช่น ซับไตเติ้ลเกม) โปรแกรมจะดึงข้อความตรงนั้นมาแปลให้ทันที

ระบบแปลอัตโนมัติ (Auto Mode): โปรแกรมจะคอยเฝ้ามองจุดที่ครอบไว้ตลอดเวลา ถ้าตัวหนังสือในเกมเปลี่ยน มันก็จะแปลประโยคใหม่ให้เองแบบเรียลไทม์ (ทุกๆ 1.5 วินาที)

สกัดคำศัพท์น่ารู้ (Vocab Extractor): ไม่ได้แปลแค่ประโยคยาวๆ อย่างเดียว แต่มันจะดึงคำศัพท์แยกเป็นคำๆ ออกมาให้ด้านข้างด้วย

สมุดจดคำศัพท์ส่วนตัว (Save to JSON): คลิกที่คำศัพท์ที่ไม่รู้เพื่อบันทึกเก็บไว้ท่องจำทีหลัง (เซฟลงไฟล์ JSON) หรือกดปุ่มลูกศรเพื่อเด้งเข้าเว็บ Longdo Dictionary ทันที

ระบบคีย์ลัดทะลุจอ (Global Hotkeys): สามารถกดคีย์บอร์ด (เช่น F2, F3) เพื่อสั่งงานโปรแกรมได้เลยแม้ขณะกำลังบังคับตัวละครในเกมอยู่

ซ่อนตัวแนบเนียน: กล่องแปลภาษาโปร่งใส ไม่บังเกม และสามารถย่อขยาย หรือซ่อนเก็บได้เมื่อไม่ต้องการ

2. หลักการทำงาน (วิธีที่มันทำงานเบื้องหลัง)
โปรเจคนี้คือการเอาเทคโนโลยีหลายๆ อย่างมาต่อกันเหมือนจิ๊กซอว์ครับ:

Capture (จับภาพ): เมื่อเล็งกรอบหน้าจอแล้ว โปรแกรมจะทำการ "แคปรูปภาพ" บริเวณนั้นอย่างรวดเร็ว

OCR (อ่านข้อความ): ส่งรูปภาพที่แคปได้ไปให้ AI (Tesseract) สแกนดูว่าเส้นสายในรูปนั้นคือตัวอักษร A-Z อะไรบ้าง แล้วแปลงภาพให้กลายเป็น "ข้อความ (Text)"

Translate (แปลภาษา): ส่งข้อความภาษาอังกฤษที่อ่านได้ไปเข้า API ของ Google Translate เพื่อแปลเป็นภาษาไทย

Extract (แยกคำ): เอาข้อความมาตัดคำซ้ำออก กรองเอาเฉพาะคำศัพท์หลักๆ ส่งไปแปลเป็นคำๆ เพื่อทำสมุดคำศัพท์

Display (แสดงผล): เอาผลลัพธ์ทั้งหมดมาแสดงบนหน้าต่างล่องหนที่สร้างขึ้นมาซ้อนทับหน้าจอปกติ

3. เครื่องมือที่ใช้สร้าง (Tech Stack)
คุณได้ประกอบโปรแกรมนี้ขึ้นมาด้วยภาษา Python และใช้ไลบรารี (Library) ระดับท็อปหลายตัวมารวมกัน:

PySide6 (Qt): หัวใจหลักในการสร้างหน้าต่างโปรแกรม (GUI) ทำให้สร้างกล่องโปร่งใส ลบขอบหน้าต่าง และทำปุ่มสวยๆ ได้

mss: ไลบรารีสำหรับแคปหน้าจอที่ทำงานได้รวดเร็วมาก (เร็วกว่าแคปภาพปกติ) เหมาะกับการทำเรียลไทม์

pytesseract: เครื่องมือสกัดข้อความออกจากรูปภาพ (Optical Character Recognition - OCR) ที่ทรงพลังของ Google

googletrans: ตัวช่วยดึงข้อมูลจาก Google Translate เอามาแปลประโยคและคำศัพท์

keyboard: ไลบรารีพิเศษที่คอยดักจับการกดปุ่มคีย์บอร์ด (Hotkey) ไม่ว่าคุณจะคลิกเมาส์อยู่ที่หน้าต่างไหนก็ตาม

ThreadPoolExecutor: ระบบทำงานแบบ Multi-threading ช่วยให้โปรแกรมแอบไปคิดคำแปลอยู่เบื้องหลัง โดยที่หน้าจอ UI ไม่ค้างหรือกระตุก
